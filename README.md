# 🐢 3D 生态缸

Three.js 立体生态鱼缸：玻璃缸、程序化红耳龟、14 种程序化鱼、水草、沉船 / 贝壳、取暖灯、昼夜。**生态规则从 2D 版完整移植**：投食→排泄→废物→水质，鱼会饿 / 生病 / 死，乌龟会捕猎，吃饱水质好会在水草边产卵。

**TP制作** —— 场景、乌龟、全部鱼类均为程序化建模，无第三方素材，无署名负担。

## 打开方式

多文件拆分，需 **HTTP 托管**（如 GitHub Pages）后访问，`file://` 打不开（ES module 跨域限制）。three.js 走 CDN，需联网。

## 操作

- **点一下鱼缸** = 在点击处投食；**长按鱼缸** = 打开工具箱；**拖动** = 旋转；**双指 / 滚轮** = 缩放；10 秒不动自动环绕。点中水草可修剪 / 照料 / 拨动。
- 左上药丸 = 水状态（水质 / 氧气 / 废物三色点），点开看详情条、鱼数 / 卵数、黄色鱼情建议。
- 首次打开有 3 步新手引导（只显示一次）。
- 工具箱：13 个圆形按钮（4 列），点按即触发；无 ✕，点"工具箱"按钮或弹窗外背景关闭。

| 工具箱按键 | 作用 |
|------|------|
| 投食 | 撒饲料（鱼吃→产废物） |
| 加鱼 | 加一条 14 种里随机品种（上限 36 条） |
| 换水 | 废物减半、氧气 +25% |
| 过滤 | 开关：持续净化 + 增氧（默认开） |
| 昼夜 | 白天 / 黑夜（夜晚取暖灯变主光源，鱼沉底休息、龟睡觉） |
| 特效 | 电影级后期（泛光 / 颗粒 / 调色），卡顿可关 |
| 修剪 | 防疯长（修剪轻微增加废物） |
| 狂暴 | 危险：20 秒追逐所有鱼（小鱼会躲进沉船） |
| 全屏 | 全屏观赏 |
| 成就 | 查看 8 个成就（孵化/混种/满群/晒背/清道夫/换水/水质） |
| 音效 | 开关（含水下环境音） |
| 高清 | 开关：像素比 2↔1，卡顿可关 |
| 重置 | 二次确认后清空存档重开 |

## 生态反馈（P2）

- 水质浑浊可视化：废物越高，水色越浑绿、雾越浓
- 缺氧浮头：氧气 <25% 时鱼群上浮到水面附近
- 废物颗粒：悬浮微粒随废物浓度变密
- 药丸显示最差项：水质/氧气/废物谁最差显示谁

## 全自动（无需人工干预）

- 饿死预警：有鱼 hunger<0.12 即在最饿鱼附近投 3 粒（8 秒冷却）
- 水质 <60% 自动换水直到 100%
- 存活 <8 条时每 40 秒在水草边下 2~4 粒随机品种鱼籽（上限 36 条 / 8 卵）
- 水草平均高度超 85% 自动修剪
- 过滤默认开启

## 生态规则（与 2D 版一致）

- 废物↑（鱼代谢 / 残饵 / 尸体 / 过密）→ 水质↓；水草 + 过滤 + 换水 → 废物↓
- 白天水草产氧，夜晚耗氧；过滤增氧
- 鱼：饥饿→找食；吃饱长铠甲（防乌龟）；紧迫时体色发红
- 繁殖：成年鱼吃饱、水质 >50%、氧气足 → 求偶 → 水草边产卵 → 孵化；同种→纯种幼鱼，异种→混种（颜色混合 + 花纹二选一）
- 乌龟：饿了捕猎（小鱼 / 卵 / 残饵 / 尸体；铠甲鱼吃不动，躲进水草或沉船就安全）；定时上浮换气；夜晚沉底睡觉；晒背时消化
- 5 秒自动存档（localStorage，键 `fishtank-3d-save-v1`，v3 格式），刷新 / 重进继续

## 鱼种（14 纯种 + 混种）

草金 / 扇尾 / 珍珠 / 锦鲤（红白）/ 小丑鱼 / 蓝吊 / 黄吊 / 火焰魔 / 麒麟鱼 / 摩尔神像 / 小鲨鱼 / 神仙鱼 / 孔雀鱼 / 红绿灯；异种交配产混种幼鱼。

```

改某域只动对应对象；未来若拆模块，每个对象整体搬走即是模块边界。
```

## 关键参数

- `MAX_FISH=36`，`MAX_EGGS=8`
- 开缸 9 条（3 金鱼 + 2 锦鲤 + 小丑鱼 / 蓝吊 / 黄吊 / 麒麟鱼）
- 逐帧零分配：更新路径无 `new` 分配；鳍纹理按色缓存；鱼眼材质共享
- 夜晚取暖灯为主光源
