⚙️ 鱼缸管理

生态是怎么运转的
· 投食 → 鱼吃饱 → 产生废物 → 废物多了水质变差
· 水草吸收废物、白天释放氧气；过滤机 24 小时净化+增氧
· 废物爆表或缺氧，鱼会生病甚至死亡；尸体要尽快被乌龟清理掉
· 鱼吃饱、心情好、水质佳时会在水草边产卵，颜色会遗传混搭
操作
· 点一下鱼缸 = 在点击处投食（可连点）
· 长按鱼缸 = 打开这个面板
· 工具栏按钮 = 投食 / 换水 / 开关过滤 / 加鱼 / 切换昼夜
· 右下角 🧰/⌄ = 收起或展开底部工具栏（横竖屏通用）
· 每 5 秒自动存档，刷新/重进后继续；真要重开用管理面板「↺ 重置鱼缸」
⚠️ 乌龟狂暴模式下乌龟会攻击所有鱼，慎用。
